# 基准测试方法与复现

## 最终批次与环境

仓库仅收录最终批次 20260922-005203-daabfc，原始数据位于 [final-20260922](../data/data/final-20260922/)，包含配置、环境、输入哈希、启动预检、逐次原始事件、上下文和完成状态。最终采样顺序为 ColdFirst，普通 autotest 账户运行。实际环境见该目录的 environment.json；CPU 为 Ryzen 9 7950X，内存 32 GiB，Windows 11 Build 26200，SSD 为 Samsung 990 PRO，HDD 为 ST4000VX000。

Electron 产物部署在对应 SSD/HDD；系统、页面、视频、配置和日志位于 SSD。A 是基线，C 是拆分＋预读。每次实验为两种存储创建新的随机部署目录，同一批次持续使用固定路径。每个路径只启动预检一次，验证视频回调并初始化配置；正式样本使用初始配置的独立副本。

## 采样顺序

先完成 80 次冷启动，每个样本独立重启。随后在最后一次开机内进行 20 次热身（每路径 5 次），再进行 80 次热启动。每条件、每版本正式 n=20。每轮依次覆盖四个路径，下一轮反转顺序；每盘各有 10 轮 AC、10 轮 CA。完整顺序冻结在 config.json。

冷启动指重启、登录并等待环境就绪后的首次被测 Electron 启动，保留 Windows 默认缓存和预取，不声称所有缓存已清空。一次预检也可能产生学习记录。热启动在预热后创建新进程，所有热身和热样本位于同一次开机。

使用当前用户 HKCU Run 登录续跑。测量前核对独占、解锁的交互桌面，开机至少 120 秒，连续三次总 CPU ≤10%，间隔 2 秒，最多等待 20 分钟；繁忙时记录占用进程。每次记录控制器 CPU、I/O、内存优先级，要求 Normal / 2 / 5。这是控制器检查，不代表直接测得 Electron 自身优先级。

## 计时与校验

起点是 Windows 原生进程创建时间，包含启动器与预读开销。原生时钟辅助程序结合 GetProcessTimes、GetSystemTimePreciseAsFileTime 与 QueryPerformanceCounter；渲染进程在回调入口记录时间，通过 IPC 时钟交换对齐。

- APP READY：进程创建至主进程 app.whenReady 回调。
- 视频呈现回调：首次收到可见视频的 requestVideoFrameCallback，不保证对应解码第一帧或物理屏幕输出。
- 页面包含本地 SVG 图标及 1280×720 静音视频，不访问网络。素材见 [MEDIA.md](../code/harness/MEDIA.md)。
- 校验进程退出、stderr、窗口和页面可见、未最小化、视频未暂停、720p 尺寸、有效 presentedFrames、无网络请求，以及时钟不确定度和漂移门槛。

准备完成后冻结输入，每次测量之后校验产物与程序哈希，避免冷启动前读取产物。完整性结果记录在逐次 result.json；离线复算验证公开归档与原始事件，不能重新验证未随仓库分发的二进制或当时物理条件。

## 统计与结论范围

P50/P90 使用排序后的线性插值 i=(n−1)×p；差值为改动版减基线，百分比以基线为分母。差值在舍入前计算，展示毫秒取整、百分比一位小数。两个终点来自同一次启动，正式启动总数为 160。

本批冷启动视频回调 P50 在 SSD/HDD 上分别减少 22.4%/36.9%；HDD APP READY P90 增加 26.5%，热启动存在约 8–20 ms 的 P50 开销。HDD 改动版 READY 在第 10 轮出现明显下降，未单独确认原因；本批没有 ETW 预取事件，不能据此归因于系统学习。

此前先热后冷批次曾出现 SSD 冷启动劣化。本仓库仅收录最终批次，不合并历史数据；最终结果只适用于本机、所测页面和上述顺序，不表示所有启动历史与设备均有相同收益。

## 离线复算与复现

运行 `node code/scripts/analyze.cjs` 会验证最终批次 SHA256.json、180 次启动的原始记录、采样顺序、账户与冷热开机约束，并重新计算与核对结束时保存的统计。只更新 data/reports/，不启动 Electron 或重启系统。

在另一台机器上按 README 指定两组产物和 SSD/HDD 路径，使用 -Order ColdFirst -Count 20 -Warmups 5。运行提示、自动登录准备和停止方式见 [运行说明](RUNNING.zh-CN.md)。构建信息保存在 data/provenance/builds；新构建应保留独立标识。新实验由当前账户重新初始化配置，不要求复用本机配置字节。
